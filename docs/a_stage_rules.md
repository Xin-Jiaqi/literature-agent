# A 阶段全文获取与建档规则（S 级论文）

> 适用范围：后续所有 S 级论文的 A 建档流程。本规则在 A. 重要文献快速建档 Skill 之外补充“全文/SI 获取”要求，不与 Skill 的输出格式冲突。
> 已完成的测试论文（2608.06326、2608.03492）不重新执行。

## 1. A 执行前：先检查 SI 是否存在

对每篇 S 级论文，在执行 A 前必须检查是否存在 Supporting Information / Supplementary Material：

- 检查正文首页脚注、arXiv 页面（含 anc 附属文件列表）、期刊页面中是否有 SI 链接或说明；
- 检查正文中对 SI 的引用方式（如 “see Supporting Information Section X / Fig. S4”），统计 SI 被引用承担的功能。

## 2. 判定 SI 是否为核心依赖

- **必须尝试获取官方 SI**：正文明确把以下内容放在 SI 中——
  - 核心公式（微观公式、完整推导、张量表达式）
  - 关键验证（支撑主结论的数值/实验证据）
  - 普适性证明（推广到其他材料/体系的论证）
  - 计算细节（方法、参数、收敛性测试）
- **不强制下载**：SI 只是额外数据或次要补充（如扩展图表、材料清单、次要对比）。

判断依据只来自正文对 SI 的表述，不猜测。

## 3. SI 获取

- 优先官方渠道：期刊 SI 页面、arXiv 附属文件（anc）。
- 获取成功后：将 SI 与正文一起作为 A 的阅读依据，并在 A 的“本次阅读依据”中写明“正文 + SI”。
- 获取失败或 SI 本身不可得：不阻塞 A，按第 4 条处理。

## 4. 无法获取 SI 时的强制要求

- A 中必须明确列出“哪些结论依赖 SI、当前未核实”；
- 不允许根据正文中的引用内容猜测 SI 结果，也不得假装阅读过 SI；
- 定量结论若仅在 SI 中出现，A 中只能标注“待核实”，不能转述为已确认数字。

## 5. 记录

- SI 检查结果（存在与否、是否核心依赖、是否获取成功、未核实项）写入该论文的 A 建档文档；
- 若属于自动化测试，同时记入 `a_test_report.md` 的“遇到的问题”。
