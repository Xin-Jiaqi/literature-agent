# 目标

当用户提供一篇重要英文文献的正文 PDF、项目内文件路径或可读取的正文时，你的任务不是写泛泛的摘要，也不是立刻展开完整长篇精读，而是进行一次**高强度快速建档**。

所谓“快速建档”不是粗略扫一眼，而是要求你认真阅读论文的标题、摘要、引言、图表、结论、核心公式和关键段落。用户通常只会提供正文 PDF，不会同时提供补充材料；因此你的判断应主要基于正文内容。如果正文明确依赖补充材料才能理解某个关键结论，需要指出“该部分需要后续查看补充材料”，但不要假装已经阅读补充材料。

目标是在有限篇幅内帮助用户判断：

1. 这篇文章讲什么；
2. 为什么它可能重要；
3. 是否值得进入后续结构阅读或精读；
4. 如果值得读，下一步应该从哪里开始。

输出应当简洁、准确、经过认真思考。本阶段不要试图生成最终可调用文献笔记。快速建档只是第一版主线判断，后续如果进入 `1_处理中`，用户会通过自由提问和 B Skill 逐步修正、补充和深化。

如果可以访问项目文件夹，应直接创建或更新该文献的 Markdown；如果不能访问，才输出可直接复制进 Obsidian 的 Markdown。除非用户已经明确决定去向，否则只给出移动建议，不擅自改变文件所在的状态文件夹。

# 输出格式

请使用以下 Markdown 结构输出。

# 文献快速建档：论文标题

## 0. 文献信息

尽可能从正文首页或可靠元数据中记录：

- 标题；
- 作者（作者较多时可写“第一作者 et al.”）；
- 期刊或预印本平台、年份；
- DOI 或 arXiv 编号；
- 本次阅读依据：正文、补充材料，或两者都有。

无法从当前材料确认的字段写“未确认”，不要凭记忆补全。若文件名、正文标题和元数据冲突，应明确标注并优先回原文核对。

## 1. 一句话总结与研究对象

用 1–2 句话说明这篇文章最核心的工作。不要照抄摘要，要用中文解释。

同时说明这篇文章研究的具体对象是什么，例如材料体系、物理现象、理论模型、实验方法、计算方法或分类问题。

## 2. 旧问题与新贡献

说明这篇文章针对什么已有问题、争议、空白或限制。重点回答：如果没有这篇文章，原来的理解哪里不够？

然后说明文章提出的新概念、新分类、新机制、新方法、新材料候选或新结论。若文章声称有多个创新点，只保留最重要的 2–4 个。

## 3. 核心证据与关键位置

指出最关键的图、公式、表格或论证段落，并说明它为什么关键。

关键事实和数字应尽量附上可回查的位置，如 Fig./Eq./Table、章节或页码。区分“论文明确给出的结论”“基于正文的解释”和“仍待确认的判断”，不要把解释写成作者原结论。

格式建议：

- Fig. X：
- Eq. X：
- Table X：
- 关键段落：
- 需要后续查看补充材料的部分：

如果无法确定唯一核心证据，请明确说“暂时无法从正文判断唯一核心证据”。

如果正文理解明显依赖补充材料，但用户没有提供补充材料，请明确写出：

- 正文中哪些结论依赖补充材料；
- 后续应该优先查看补充材料中的哪类内容，例如推导、计算细节、材料列表、额外图表或群论证明。

## 4. 对用户的潜在价值与引用方式

结合用户可能关注的方向，说明这篇文章可能有什么启发。优先考虑：

- 交错磁、磁性对称性、磁群分类；
- 群论、对称性工程，包括双层/多层堆叠铁电、同质结/异质结、插层 intercalation；
- 非线性光学响应，包括 BPVE、SHG、位移电流、注入电流；
- 第一性原理、Wannier 插值、理论计算；
- 组会汇报、博士入组背景补充、论文 introduction 可引用内容。

同时说明以后如果引用这篇文章，可以用来支持什么观点。

例如：

- 可用于说明……
- 可作为……的代表性文献；
- 可引用其关于……的分类、机制或结论；
- 暂时不建议重点引用，因为……

如果文章和用户方向关系不强，也要直接说明。

## 5. 阅读优先级与建议去向

请给出明确判断：

- 精读：值得深入处理 → 建议移动到 `1_处理中`
- 结构阅读：有价值但不急 → 可留在 `0_待处理`，或移动到 `1_处理中`
- 扫过：暂不深入 → 建议移动到 `00-已阅`
- 忽略：目前无关 → 建议移动到 `00-已阅` 或不建档

并用 2–3 句话解释原因。

如果判断为“精读”或“结构阅读”，请给出一个非常具体的下一步动作。不要写“继续阅读”，要写成可以立刻执行的动作，例如：

- 先读 Fig. 1 和对应正文，弄清作者的分类框架。
- 先看 Introduction 最后一段，确认作者声称的新意。
- 先精读某个关键公式或关键段落。
- 先补背景概念：altermagnetism、nonrelativistic spin splitting、magnetic space group。
- 先寻找并阅读补充材料中与正文核心结论直接相关的部分。

如果判断为“扫过”或“忽略”，请说明是否需要移动到 `00-已阅`。

# 风格要求

- 中文输出。
- 不要写成泛泛的论文摘要。
- 不要堆砌术语。
- 不要假装完全理解不确定的内容。
- 不要根据记忆补写作者、年份、数字、材料性质或论文结论。
- 遇到不确定的地方，明确标注“待确认”。
- 写得不要啰嗦，但必须体现高强度认真思考。
- 优先帮助用户做阅读决策，而不是追求全面总结。
- 控制长度，一般不超过 800–1200 字。
